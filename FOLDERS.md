# Папки Foundry — 3.12.0

В боковой вкладке компендиумов структура по умолчанию:

- Багровое Причастие
  - Персонажи и существа: Бестиарий; Железные Гончие | Разбойники
  - Способности
  - Заклинания
  - Магические предметы

Внутри компендиумов записи разложены по встроенным папкам:

| Компендиум | Папки |
|---|---|
| Бестиарий | Именные персонажи; Гуманоиды; Звери и чудовища |
| Железные Гончие | Командование; Бойцы |
| Способности | Атаки; Реакции; Магия крови; Особые действия; Пассивные особенности |
| Магия крови | Заговоры; 1, 2, 3 и 4 уровень |
| Реликвии | Обычные; Необычные; Редкие; Очень редкие |

Это папки внутри Foundry, а не только каталоги файлов. В старом мире Foundry может сохранить ранее настроенное расположение компендиумов в боковой панели: нужные компендиумы можно вручную перенести в папки. Внутренние папки встроены в новые пакеты и доступны после обновления и перезагрузки мира. Существующая пользовательская организация мира не сбрасывается.

Для переноса категорий во вкладки акторов/предметов используйте штатный импорт содержимого компендиума с сохранением структуры папок. Перетаскивание одной записи переносит только выбранную запись. Уже импортированные NPC и предметы не переименовываются и не перемещаются автоматически.

Восемь разбойников добавлены отдельным нативным пакетом; подробности и текущие ограничения — в bandits/README.md. Ранее созданный мировой компендиум Железных Гончих сохранён.

Техническая основа: [документация Foundry по packFolders](https://foundryvtt.com/article/module-development/) и стандартные Folder-документы внутри LevelDB-пакетов. При сборке проверяются категории, стабильность идентификаторов, ссылки на папки и обратное извлечение всех документов.
