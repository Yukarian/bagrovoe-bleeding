# Багровое Причастие — Кровотечение

Независимый модуль для Foundry VTT v14 и D&D5e 6.0.5. Не требует сторонних модулей.

## Публикация
1. Манифест подготовлен для репозитория `Yukarian/bagrovoe-bleeding`.
2. Загрузите все файлы в репозиторий `bagrovoe-bleeding` (включая скрытую папку `.github`).
3. Создайте тег `v3.0.0` и отправьте его в GitHub. GitHub Actions соберёт ZIP и опубликует релиз вместе с `module.json`.
4. Установите модуль по ссылке `https://github.com/Yukarian/bagrovoe-bleeding/releases/latest/download/module.json`.

Исходный код не проходил интеграционного тестирования в запущенной Foundry: сначала проверьте на тестовом мире.
