# Суйгу — жители

Восемь авторских гражданских NPC, созданных по описанию Суйгу в пользовательском Notion. Это новые персонажи, а не существующие записи канона. Источник географии: https://app.notion.com/p/292b6f7340ee802f83ddddd02b3a1e5a

Компендиум «Суйгу | Жители» разделён по районам. Имена, профессии, внешность, характер, цели, встречи и зацепки доступны в биографиях. Все NPC имеют ПО 0, обычные навыки и простую атаку для самообороны. Магия крови не включена. Профессиональные особенности описательные. Для шести заготовок происхождение не задано: его можно выбрать под кампанию. Пока используются стандартные изображения персонажей.

- **Нэри Вэйл** — Лодочница, Квартал Белых Листьев.
- **Орин Таль** — Ремонтник светильников, Лесной Предел.
- **Сэли Арвен** — Сушильщица трав, Поля Аравэна.
- **Вэса Лин** — Переплётчица, Фиолетовый Переплёт.
- **Тален Ро** — Пекарь, Лесной Предел.
- **Эйра Ним** — Помощница сцены, Лесной Предел.
- **Иллен Са** — Младший писарь, Голубой корень.
- **Борен Лист** — Чистильщик каналов, Квартал Белых Листьев.

Импортируйте NPC в мир. В управлении поселением добавьте именного жителя и выберите его лист; затем назначьте дом и должность. Население города и здания автоматически не создаются. Биографии содержат зацепки ведущего, поэтому видимость компендиума для игроков по умолчанию отключена.
