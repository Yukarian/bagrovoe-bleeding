# Настройки способностей заражённых NPC (v3.2.0)

Настраивайте способность в **flags предмета** NPC: `flags.bagrovoe-bleeding.abilities`.
Это техническая метаинформация, **не помещайте её в описание** способности.

Пример для «Разрывающего укуса» Кровавого гончего:

```json
{
  "flags": {
    "bagrovoe-bleeding": {
      "abilities": {
        "bleed": {
          "levels": 1,
          "bonusLevelsIfBleeding": 1,
          "dc": 13,
          "count": 1
        },
        "onHit": {
          "requiresBleeding": true,
          "tempHP": 3,
          "oncePerTurn": true
        }
      }
    }
  }
}
```

Пример обычного «Укуса» с временными хитами, но без кровотечения:

```json
{
  "flags": {
    "bagrovoe-bleeding": {
      "abilities": {
        "bleed": false,
        "onHit": {
          "requiresBleeding": true,
          "tempHP": 3,
          "oncePerTurn": true
        }
      }
    }
  }
}
```

## Доступные параметры

| Параметр | Поведение |
| --- | --- |
| `abilities.bleed.levels` | Уровни при провале спасброска Телосложения, 1–5 |
| `abilities.bleed.dc` | Сл спасброска, 1–99 |
| `abilities.bleed.count` | Количество кубиков урона, 1–10 |
| `abilities.bleed.bonusLevelsIfBleeding` | Дополнительные уровни, если цель уже кровоточит |
| `abilities.bleed.requiresBleeding` | Не пытаться наложить кровотечение, если его ещё нет |
| `abilities.onHit.requiresBleeding` | Побочный эффект при попадании только по кровоточащей цели |
| `abilities.onHit.tempHP` | Минимум временных хитов атакующего после попадания; с большим количеством уже имеющихся временных хитов не складывается |
| `abilities.onHit.healHP` | Лечение атакующего после попадания, без превышения максимума |
| `abilities.onHit.oncePerTurn` | Не чаще раза за ход **для данного предмета** (по умолчанию true) |

Отсутствие блока `bleed` или значение `false` означает, что эта атака не вызывает кровотечение, если не указаны старые совместимые флаги.

Используйте обычную активность **attack** D&D5e для атак, результат которых может вызвать данные эффекты. Ведущий должен быть онлайн, а выбранная цель (T) должна попасть в сохранённые системой evaluatedTargets. После попадания модуль обрабатывает спасбросок цели и состояние кровотечения.

**Совместимость:** старые флаги `inflict`, `houndBite`, `houndRend` оставлены для ранее импортированных монстров. Новые NPC должны использовать `abilities`.

**Ещё не реализовано:** автоматическое преимущество броска атаки по кровоточащей цели. `advantageIfBleeding` сейчас не поддерживается как готовый параметр; преимущество пока выбирается вручную. Некоторые нестандартные способности боссов могут потребовать дальнейшего расширения движка.

**Проверка в Foundry:** код требует испытания на вашей версии Foundry V14 / D&D5e 6.0.5. Изменение в ветке main не равно опубликованному релизу для автоматического обновления.
