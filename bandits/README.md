# Железные Гончие — банда Родерика

Начиная с 3.12.0 восемь NPC поставляются в отдельном нативном компендиуме «Железные Гончие | Разбойники». Папка «Командование»: Родерик Варн (ПО 6), Марта Грейвс (ПО 3), Гаррет Хольм (ПО 2), Сайлас Вейн (ПО 2). Папка «Бойцы»: ветеран (ПО 1), рядовой, арбалетчик и разведчик (ПО 1/2).

Исходные листы: `packs-src/iron-hounds.json`. Атаки имеют штатные активности с бонусами и формулами урона. Условные особенности, командные приказы, парирование и дополнительные эффекты этой банды пока описаны текстом и исполняются ведущим; полной автоматизации для них нет. Изображения пока стандартные: исходные PNG-токены банды не были добавлены в репозиторий.

Старый загрузчик мирового компендиума убран. Если `world.iron-hounds` уже создан ранее, модуль не удаляет и не перезаписывает его. Обновлённый встроенный компендиум доступен отдельно; свои правки старых NPC сохраните перед заменой.
