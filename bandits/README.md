# Разбойники и Железные Гончие — 4.9.0

Четыре независимых шаблона в папке «Разбойники — универсальные»: копейщик ПО 1/2, арбалетчик ПО 1/2, разведчик ПО 1, ветеран ПО 2. Командование: Гаррет Хольм ПО 2, Сайлас Вейн ПО 2, Марта Грейвс ПО 3, Родерик Варн ПО 6.

Восемь новых рисованных токенов соответствуют оружию и роли; отдельных портретных артов нет. Универсальные бойцы без герба и названия банды, с несвязанными токенами.

[Лагерь, баланс, награды и ресурсы деревни](CAMP.md). Этот материал также включён в компендиум поселений → Приключения → Лагерь Железных Гончих.

Штатные активности: атаки, спасброски, дополнительный урон, лечение, реакции и бонусные действия; заряды и перезарядки. Условные эффекты, перемещение, ауры и последовательность мультиатаки выполняет ведущий. Старые импортированные NPC не перезаписываются.
