# Железные Гончие — банда Родерика

Отдельный раздел **bandits** внутри модуля «Багровое Причастие».

## Состав
- Родерик Варн (ПО 6)
- Марта Грейвс (ПО 3)
- Гаррет Хольм (ПО 2)
- Сайлас Вейн (ПО 2)
- Ветеран Железных Гончих (ПО 1)
- Рядовой Железных Гончих (ПО 1/2)
- Арбалетчик Железных Гончих (ПО 1/2)
- Разведчик Железных Гончих (ПО 1/2)

При запуске мира под Мастером файл `bandits/iron-hounds.js` создаёт мировой компендиум `world.iron-hounds` и добавляет отсутствующих NPC. Существенные механики изложены в особенностях; автоматизация срабатывания некоторых способностей и комбинаций пока требует дополнительной проверки в живой Foundry.

**Важно:** здесь пока размещены текстовые листы с формулами атак и особенностями; исходные PNG-токены из отдельного ZIP пока не размещены в GitHub. Изображения временно стандартные. Не перезаписываются существующие NPC с одинаковыми именами.

Изменения не затрагивают компендиум и сценарии Багрового Причастия.
