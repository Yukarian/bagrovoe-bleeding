# 3.12.0 — Железные Гончие и папки Foundry

Добавлены восемь NPC банды Родерика в отдельный нативный компендиум с папками «Командование» и «Бойцы». Старый загрузчик мирового компендиума заменён готовым пакетом; существующие мировые копии сохранены.

Весь контент разложен по папкам Foundry: NPC по категориям, способности по назначению, заклинания по уровню, реликвии по редкости. В боковой панели задана общая структура «Багровое Причастие». Подробнее — FOLDERS.md.

Банда пока использует стандартные изображения. Атаки настроены, условные особенности и командные эффекты требуют ведущего. Боевые скрипты основного модуля не изменены.

После обновления перезагрузите мир. Старые листы автоматически не заменяются. В уже настроенном мире расположение компендиумов в боковой панели может сохраниться прежним; внутренние папки включены в новые пакеты.
