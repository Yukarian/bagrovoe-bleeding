# Мир Ортес 6.6.1 — исправление обновления книг NPC

Исправлена ошибка Foundry V14: `Flag scope "bagrovoe-content" is not valid or not currently active`. Старые метки происхождения NPC теперь читаются напрямую из сохранённых флагов, без обращения к API отключённого старого модуля. Включать bagrovoe-content не требуется.

Обновление сначала отбирает подходящих NPC. Если обновлять некого, бестиарий не загружается; посторонние и потерявшие актёра токены не инициализируются. Одновременные запросы используют одно обновление.

Сообщение ошибки указывает шаг и имя NPC, если он уже выбран. Оно больше не утверждает, что резерв сохранён, когда ошибка произошла до его создания. Существующие резервные записи и защита от повторной обработки незавершённого обновления сохранены.

Предоставленная ошибка возникала при чтении исходных NPC, до изменения листов. Для неё не нужно удалять резервные записи или заново импортировать персонажей. Обновите модуль и перезапустите мир.

285 автоматических тестов и сборка 8 компендиумов прошли, включая воспроизведение запрета неактивной области флагов. Живая сессия Foundry V14 не запускалась.
