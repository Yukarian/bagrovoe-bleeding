# 3.10.3 — Парадные токены именных NPC

Добавлены вторые варианты для Эдрика Вальтера и Эмили Ясати: индивидуальные декоративные рамки и фон, подготовленные с помощью imagegen. Прежние файлы сохранены и остаются основными. Характеристики и боевые механики не менялись.

В настройках изображения токена выберите файл из папки `modules/bagrovoe-bleeding/assets/tokens/named/`:

- Эдрик: `edrik-valter.png` — костяные шипы, рубины и тёмное серебро.
- Эмили: `emili-yasati.png` — розы, серебро и багровое сердце.

Чтобы применять вариант к новым токенам, измените изображение в прототипе токена на листе NPC. Для уже размещённого токена измените его собственное изображение. Прежние варианты находятся непосредственно в `assets/tokens/` под теми же именами.
