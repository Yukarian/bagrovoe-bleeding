# Мир Ортес 6.19.0

100 событий деревни и бастиона для к100, по умолчанию раз в 7 игровых дней. Автоматические последствия новых событий затрагивают только казну; остальные решения разыгрываются за столом.

Одноразовые события после применения заменяются продолжениями в том же диапазоне. Первый приход Альдевальда Морканта сменяется вестями о поиске воскрешения. После трёх визитов Валькрейна приезжают его посыльные. Пропуск события не расходует его лимит.

Сохранены история, ручной вызов, редактирование и настройки диапазонов. Полный список: BASTION_EVENTS.md. Обновление касается событий; остальные разделы управления деревней этим выпуском не переделываются.
