# 4.9.0 — Разбойники и лагерь

Перепроверены восемь NPC: исправлены роли токенов, нейтральные шаблоны бойцов, ПО разведчика и ветерана, атаки командиров, штатные активности и расход применений. Восемь рисованных токенов без отдельных артов.

В компендиум поселений добавлен журнал «Лагерь Железных Гончих»: состав для пяти героев 5-го уровня, варианты 2024/2014, тактика, личная награда и груз для Вестерхольма. Личная добыча и общинные ресурсы разделены; автоматической выдачи нет.

Вестерхольм из 4.8.0 включён. Условные боевые эффекты частично ручные; подробности в bandits/CAMP.md. Живой прогон в Foundry не выполнен.
