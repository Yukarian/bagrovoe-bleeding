# Мир Ортес 6.3.0

Казино полностью убрано по запросу пользователя: игровые окна, касса, кнопка на панели и анимации больше не подключаются.

Функции модуля возвращены к версии 6.0.0. Развитие Вестерхольма, календарь, штатные Оплоты, персонажи, предметы и боевые механики сохранены.

Номер версии повышен, чтобы установленная 6.2.0 могла обновиться обычным способом. Обновите модуль и перезапустите мир. Старые данные казино в мире автоматически не удаляются; совершённые операции с золотом не отменяются автоматически.
