# Мир Ортес 6.18.2

Домен мира: Ободряющая связь накладывается без подтверждения ведущего. В стандартном окне броска к20 участник выбирает добавление 1к4, который входит в тот же бросок. Бальзам мира оформлен как Проведение энергии с функцией лечения 2к6 + Мудрость; общий ресурс находится по идентификатору, русскому или английскому названию, при необходимости выбирается вручную. Отсутствующий ресурс можно добавить с указанием уже потраченных применений. Сопротивление урону остаётся свойством Защитной связи с 17-го уровня, не постоянной защитой участников.
