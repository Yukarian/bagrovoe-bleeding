# Мир Ортес 6.15.0 — отдельное управление событиями

Кнопка свитка и кнопка «События» открывают отдельное окно только для ведущего: очередь, каталог и история, без экономики и управления развитием.

- Поиск, изменение названия, описания, категории, условий, последствий, лимитов и диапазона к100. Создание и копирование событий.
- Ручной вызов, отдельный бросок к100, применение, откладывание и пропуск. Вызов не применяет последствия автоматически.
- Настраиваемые интервал проверок и перерыв между повторениями. Сохраняется прежний режим к20; режим таблицы к100 включается явно.
- Пересечения диапазонов запрещены; пустые числа не дают событие; 0–0 оставляет только ручной вызов. Начальная таблица: 1–52 по одному событию, 53–100 без события.
- Настройки индивидуальны для деревни. Очередь и история сохраняют исходные описания и последствия; счётчики одноразовых событий не сбрасываются.
- 360 автоматических проверок. Работа в открытом Foundry вручную не проверялась.
