# 4.1.1 — Портреты жителей Суйгу

Каждый из восьми жителей Суйгу получил отдельный арт с деталями своей профессии. Портреты назначены листам и изображениям прототипов токенов.

Обновлённые NPC находятся в «Суйгу | Жители». Для существующих мировых копий импортируйте свежих NPC или выберите изображения из modules/bagrovoe-bleeding/assets/portraits/suigu/. Боевые данные не изменены.
