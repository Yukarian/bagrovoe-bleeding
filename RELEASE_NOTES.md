# Мир Ортес 6.18.3

Бальзам мира использует штатную функцию Исцеление и штатное потребление Божественного канала. Удалены перехват применения и окно подтверждения маршрута. Модуль не применяет лечение повторно. Кнопка к4 больше не остаётся заблокированной при отказе; причины недоступности показываются. Контекст связи вынесен из копируемой конфигурации броска, поле к4 показывается в начале стандартной формы. Существующие особенности модуля обновляются при входе ведущего; заряды сохраняются.
