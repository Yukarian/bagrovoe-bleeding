# Мир Ортес 5.1.0

Добавлена Леорина Де'Астрейл — волшебница 20-го уровня и покровитель колдуна. Найти: «Ключевые NPC» → «Покровители». Имя, исходный арт и токен сохранены.

- 60 заклинаний без дублей, подготовленный набор, правильные ячейки и отдельные бесплатные применения.
- Запугивание +25, минимальный результат к20 — 10; Сл заклинаний 21, атака +13.
- Безмолвный ужас, Смертный взгляд, ограниченная проекция и учёт семи Камней Чувств.
- Проклятие стирает прошлое; новые встречи запоминаются. Освобождение из темницы не восстанавливает прошлую память.
- Исправлены импортированные действия: общий запас временных хитов Укрепления, повторные воздействия без повторной траты ячеек и сломанные ссылки на сторонние библиотеки.
- JSON для отдельного импорта включён в exports; подробности и границы автоматизации — LEORINA.md.

235 автоматических проверок прошли; все восемь нативных компендиумов собраны и проверены. Полная проверка в запущенной Foundry V14 не выполнялась. Существующие актёры в мирах не перезаписываются: импортируйте обновлённую запись из компендиума.
